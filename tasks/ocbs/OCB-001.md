# OCB-001 — Exchange: Heatmap sintetico de Open Interest
**Modulo:** Exchange / Dashboard | **Prioridad:** BAJA | **Fecha:** 2026-07-08 | **Estado:** Abierto

## DESCRIPCION

El dashboard muestra liquidaciones reales (las que ya ocurrieron). Lo que no existe es una
visualizacion de donde podrian concentrarse liquidaciones FUTURAS, que es lo que el "mapa de
liquidaciones" de Coinglass intenta mostrar.

Se puede construir una aproximacion 100% gratuita con datos publicos de Bybit:

1. Pedir historial de Open Interest (`fetchOpenInterestHistory` via ccxt/Bybit).
2. Para cada vela, tomar el delta de OI (proxy de posiciones nuevas abiertas en ese precio).
3. Asumir apalancamientos tipicos de Bybit (5x, 10x, 20x, 25x, 50x, 100x).
4. Para cada combinacion (precio de vela, apalancamiento), calcular precio teorico de liquidacion de long y short.
5. Acumular en histograma por nivel de precio -> distribucion de "densidad de liquidaciones estimadas".

Esta es exactamente la metodologia de Coinglass y similares: es una ESTIMACION, no un dato real,
porque ningun exchange revela el apalancamiento individual de cada trader.

El valor real es visual: ayuda a identificar zonas de precio donde, si el precio llega, hay
mas probabilidad de que se disparen cascadas de liquidaciones (lo que puede amplificar el movimiento
o provocar una reversion rapida).

## CRITERIOS DE ACEPTACION

- [ ] Endpoint `/api/liquidations/heatmap?symbol=BTC/USDT:USDT&hours=24` que retorna el histograma
- [ ] Panel en el dashboard que muestra el heatmap como barras horizontales por nivel de precio
- [ ] El panel deja claro con un label que es una ESTIMACION, no dato real
- [ ] El calculo no bloquea el servidor (ejecutar en background, cachear resultado 15 min)
- [ ] Apalancamientos usados documentados en el codigo para que sean auditables

## DEPENDENCIAS

Ninguna. Es una feature independiente sobre datos publicos de Bybit.
